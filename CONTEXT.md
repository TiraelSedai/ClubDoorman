# ClubDoorman

ClubDoorman - контекст Telegram-антиспам-бота, где доверенные администраторы модерируют чаты и курируют примеры для обучения классификатора.

## Язык

**Админ-чат**:
Telegram-чат, где доверенные администраторы отдают боту команды модерации и обслуживания обучающего датасета.
_Не использовать_: Control chat, moderation room

**Spam-ham запись**:
Размеченный текстовый пример, который используется для обучения бота отличать спам от легитимных сообщений.
_Не использовать_: Dataset row, sample row

**Откат датасета**:
Действие обслуживания, которое удаляет ошибочную spam-ham запись, чтобы будущие переобучения классификатора больше её не использовали.
_Не использовать_: Rollback

**Необычные буквы**:
Письменность в сообщении, которая считается подозрительной для обслуживаемых чатов и может требовать удаления, репорта или дополнительной AI-проверки.
Грузинские и армянские буквы не относятся к необычным буквам.
_Не использовать_: Exotic letters, weird letters
