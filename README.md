## Антиспам для телеграма

Изначально разрабатывался чтобы решить проблему со спамерами в чатах Вастрик.Клуба, но может использоваться и в чатах других форков, да и просто в любых больших чатах.

### Что делает бот

- Автоматически выдает капчу новым участникам, если капча не отключена для чата
- Проверяет сообщения простыми фильтрами: блеклист, слишком много эмодзи, слова с маскирующимися символами, стоп-слова, кнопки, сообщения от каналов
- При наличии `DOORMAN_OPENROUTER_API` дополнительно включает LLM-проверки текста, фото и профиля пользователя
- Для обычной модерации бесплатные чаты не используют платный LLM, но могут ходить в свой собственный эндпоинт из `DOORMAN_FREE_LLM_URL`:
  проверка сообщений и профилей идёт в фоне и не задерживает сообщение; профили с вероятностью `≥ 0.9` (90%) на эротику или быстрый заработок тоже попадают в репорт, но LLM-проверка никогда не банит и не удаляет, а только пишет реплай-предупреждение
  (оно само удаляется через 30 минут) и репортит в фолбек админ-чат. Эндпоинт недоступен - проверка просто пропускается
- Может автоматически банить или только удалять и отправлять сообщение в админку, в зависимости от настроек
- В платных чатах при `0.3 < ML-скор < 2` и успешной LLM-оценке спама `≤ 10%` отправляет репорт без удаления по ML-решению.
  Остальные проверки, включая профиль, продолжают действовать; недоступность LLM не считается низкой оценкой
- При `-0.5 < ML-скор < 0.5` во всех чатах запускает фоновую проверку Jev + Luna для автоматического пополнения spam/ham-датасета
- Подтягивает доверенных пользователей из Клуба
- Поддерживает ручную модерацию из админ-чата и команды для дообучения датасета

### Основные сценарии

- Пользователь заходит в чат, получает капчу и попадает под дополнительные проверки
- Если пользователь уже в доверенных, часть проверок пропускается
- Сообщения с явным спамом, рекламой или подозрительным профилем могут удаляться, а при включенных настройках - баниться сразу
- В админ-чат приходят уведомления о сработавших фильтрах и ручных банах

### Автоматическое пополнение датасета

При наличии `DOORMAN_OPENROUTER_API` сообщения, дошедшие до ML-проверки и получившие строго `-0.5 < score < 0.5`,
проверяются в фоне через Jev (`~typesafe/jev-latest`) и Luna (`openai/gpt-6-luna:floor`).
Это работает и в бесплатных чатах, независимо от настройки их локального LLM и `DOORMAN_LOW_CONFIDENCE_HAM_ENABLE`.
Штатная ML-проверка доверенных пользователей тоже участвует, если не отключена.
В платных чатах фоновая проверка переиспользует запрос Luna из обычной модерации; ожидание Jev не задерживает модерацию.
Обе модели используют существующий ключ OpenRouter.

Запись добавляется только при совпадении меток с уверенностью не ниже 80% у обеих моделей:
для spam Luna должна вернуть `P(spam) ≥ 0.8`, для ham — `P(spam) ≤ 0.2`;
у Jev проверяется confidence выбранной метки. Ошибка, отсутствующий/некорректный ответ или расхождение моделей не добавляют запись.
Модели получают контекст чата и сообщения, на которое отвечают; Jev анализирует текст, Luna также может видеть фото.
В датасет попадает только текст исходного сообщения с цитатой и раскрытыми ссылками, как при `/spam` или `/ham`, без дополнительного контекста моделей.

В центральный fallback-чат `DOORMAN_ADMIN_CHAT` приходит исходное сообщение и уведомление с ML-скором,
уверенностью обеих моделей, причиной Luna, ID записи и командой `/undo <id>`.
Если оригинал уже удалён или защищён от пересылки, бот отправляет текстовую копию.
Автоматическое добавление меняет только датасет и запускает штатное переобучение; в отличие от ручного `/spam`,
оно **не** добавляет фразу в отдельный список немедленного автобана и само по себе не банит и не удаляет сообщения.
Для исправления ошибочной автоматической метки сначала удалите запись через `/undo <id>`, затем при необходимости добавьте правильную через `/spam` или `/ham`.

### Админ-команды

Команды `/spam`, `/ham` и `/check` вызываются ответом на сообщение в админ-чате.

- `/spam` - добавить сообщение в датасет спама и список авто-бана
- `/ham` - добавить сообщение в датасет не-спама
- `/check` - прогнать сообщение через все проверки и показать результат
- `/unban <userId>` - снять бан и вернуть пользователя в доверенные
- `/latest [count]` - показать последние записи датасета с ID
- `/undo <id>` - удалить запись датасета и запланировать переобучение; ответ на сообщение не требуется

### Конфигурация

- `DOORMAN_BOT_API` - токен Telegram-бота
- `DOORMAN_ADMIN_CHAT` - ID админ-чата

Опционально:

- `DOORMAN_CLUB_SERVICE_TOKEN` - сервисный токен Клуба
- `DOORMAN_CLUB_URL` - базовый URL Клуба или форка, по умолчанию `https://vas3k.club/`
- `DOORMAN_OPENROUTER_API` - включает LLM-модерацию платных чатов и фоновое пополнение датасета через Jev + Luna во всех чатах
- `DOORMAN_FREE_LLM_URL` - базовый URL OpenAI-совместимого эндпоинта для бесплатных чатов, например `http://127.0.0.1:8888/v1`
- `DOORMAN_FREE_LLM_MODEL` - название модели на этом эндпоинте, обязательно если задан `DOORMAN_FREE_LLM_URL`
- `DOORMAN_FREE_LLM_API` - ключ этого эндпоинта, если он его требует
- `DOORMAN_FREE_LLM_DISABLE` - ID чатов через запятую, где отключены проверки через бесплатный LLM, например `-1001234567890,-1009876543210`; не отключает фоновое пополнение датасета через Jev + Luna
- `DOORMAN_ADMIN_CHAT_MAP` - перенаправление сообщений из конкретных чатов в отдельные админ-чаты, формат `from=to,from=to`
- `DOORMAN_STATISTICS_FALLBACK_ADMIN_CHATS` - админ-чаты, чью ежедневную статистику в 10:00 нужно отправлять в fallback-админку `DOORMAN_ADMIN_CHAT`, формат `chat,chat`
- `DOORMAN_BLACKLIST_AUTOBAN_DISABLE` - отключает автобан пользователей из блеклиста
- `DOORMAN_CHANNELS_AUTOBAN_DISABLE` - отключает автобан сообщений от каналов
- `DOORMAN_CHANNEL_AUTOBAN_EXCLUSION` - чаты, в которых автобан каналов отключен
- `DOORMAN_CHANNEL_MARKETOLOGY_EXCLUSION` - чаты, в которых не работает автобан по словам с маскирующимися символами
- `DOORMAN_CHANNELS_EMOJI_DISABLE` - чаты, в которых отключена проверка TooManyEmojis
- `DOORMAN_CAPTCHA_DISABLE` - чаты, в которых отключена капча
- `DOORMAN_LOOKALIKE_AUTOBAN_DISABLE` - отключает автобан по словам с маскирующимися символами
- `DOORMAN_BUTTON_AUTOBAN_DISABLE` - отключает автобан сообщений с кнопками
- `DOORMAN_HIGH_CONFIDENCE_AUTOBAN_DISABLE` - отключает автобан по высокой уверенности ML-модели
- `DOORMAN_EROTIC_AUTOBAN_ENABLE=1` - включает для платных чатов перепроверку эротики при оценке основной модели `openai/gpt-6-luna:floor` от 75% моделями `xiaomi/mimo-v2.6-flash:floor` и `z-ai/glm-5.3-flash:floor` с тем же промптом и автобан, если обе дают от 85%; по умолчанию выключен
- `DOORMAN_LOW_CONFIDENCE_HAM_ENABLE` - включает отправку в админку сообщений, которые ML считает не-спамом, но с низкой уверенностью
- `DOORMAN_APPROVED_ML_SPAM_CHECK_DISABLE` - отключает ML-проверку сообщений от уже доверенных пользователей
